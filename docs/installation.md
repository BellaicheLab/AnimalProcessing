# Installation

## Python package

```bash
pip install git+https://github.com/BellaicheLab/AnimalProcessing.git
```

This installs `pyanimalprocessing` and two commands: `zarrify_SAP <animal_path>` converts a Single Animal Processing folder to zarr, and `zarrify_MAP <average_path>` converts a Multiple Animal Processing average folder.

## MATLAB pipeline

SAP and MAP require MATLAB R2020b or later. See the [guides](guides/index.md) to set them up and run them.
