# Walkthrough notebooks

Two notebooks run the Python package on demo data. The pages show stored outputs. To run them yourself, use the `notebooks/` directory of the repository, which contains the demo data.

1. {doc}`Python basics <notebooks/01_python_route_basics>`: from a segmented crop of a notum movie to cell area averaged on a grid over time.
2. {doc}`Expression atlas <notebooks/02_build_an_expression_atlas>`: from stained images to a 10-gene expression atlas on a common grid, compared with the 17 hAPF atlas of the paper.
