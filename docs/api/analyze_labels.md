# Label Analysis

Per-frame region-property measurement on segmented labels. The properties to
compute are drawn from two registries: `BASE_PROPERTY_REGISTRY` (scikit-image
regionprops names) and `EXTRA_PROPERTIES_REGISTRY` (the custom properties
below).
